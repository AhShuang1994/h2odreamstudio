# 品牌配色收敛为单一靛紫，「水」改由动态承载

仓库里有两套互相打架的品牌色：旧站与 `GEO-CHECKLIST.md` 第 44 条规定的深海军蓝 `#030B1A` + 青 `#00E5FF` + teal `#06D6A0` + violet `#7B61FF`；以及 Next 重构里 `globals.css` 的近黑 `#07080b` + 靛紫 `#7c82f0`（只保留了 violet，主色青被丢掉）。**统一走后者**。

## Considered Options

- **保留降饱和的水蓝作主色**——能护住「H2O = 水」的语义、9 张 blog 插画不作废。被否。
- **回到旧品牌色全套**——`#00E5FF` 那种高饱和 cyan 是典型的廉价科技感，恰是这次重做想摆脱的东西。

## Consequences

- **唯一的例外是 hero**。首屏的液态球体保留橙／青／蓝／紫的虹彩渐变，向下滚动之后全站严格近黑 + 单一靛紫。这不是为了迁就参考图而破的例——现行站的 `assets/bg-1/2/3.webp` **本来就是多彩的**，这条只是把既有事实收进规范。Linear 本人也是这么干的：hero 背后多色光晕，其余部分单色加一个 accent。多彩只准出现在这一屏。
- 连带影响：现行站在 services（2 处）与 contact（1 处）也放了同样的多彩球体。按本决策，这 3 处须出**靛紫版**。
- 品牌名是 H2ODreamer，配色里却没有水——语义缺口由**动态**补上：`CONTEXT.md` 里的**水母题**（滴 → 涟漪 → 流 → 海）作为贯穿全站的背景层与 section 间过渡，不新增任何一屏。这也正好给了遮罩视差与 Lenis 惯性一个叙事上的理由。
- `GEO-CHECKLIST.md` 第 44 条的插画配色规范要改写。
- 9 张 blog 概念插画目前是青蓝的，需重出靛紫版。**这一项刻意延后**，不阻塞主站上线。
- `og/logo.svg` 与 `favicon.svg` 是**假 SVG**（内含 base64 PNG），改不了颜色，因此「全站靛紫」在 logo 上无法落地。logo 需重新设计并交付为真矢量路径 + `currentColor`；流程是 AI 出图找感觉 → 描成 SVG。这把本次范围从「改站」扩到了「改品牌」。
